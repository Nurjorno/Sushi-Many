# Sushi Many Landing Page

Create a modern one-page landing site for "Sushi Many", a sushi bar in Tokmok, Kyrgyzstan. Logo: a circular emblem — white circle with a red border, a red semicircle inside (evoking the Japanese sun motif), crossed dark charcoal-gray chopsticks, and a sushi roll (dark charcoal rice, orange fish topping) centered in the middle. The logo is already finalized — use it as-is in the header and footer. Color palette (derived from the logo): - Primary red: #D32F2F (accents, buttons, header) - Charcoal/dark gray: #3A3A3A (text, secondary elements) - Orange: #F5A623 (accent details, hover effects) - White: #FFFFFF (background, contrast) - Light gray section background: #F7F7F7 About the business: - Name: Sushi Many - Cuisine: Japanese — sushi, rolls, pizza, ramen, tom yum - Address: Komsomolskaya Street, 73/1, Tokmok, Chuy Region - Hours: daily, 10:00 AM – 12:00 AM - Phone/WhatsApp: +996 502-561975 - Average check: 500 som - Features: summer terrace, outdoor seating, free Wi-Fi for guests, wheelchair-accessible entrance, takeout and delivery available - Rating: 4.3 based on 117+ reviews Site structure: 1. Header — logo on the left, "Sushi Many" name next to it, nav menu (Home, Menu, About, Contact), red "Order on WhatsApp" button on the right 2. Hero section — large appetizing sushi photo/banner, headline "Real Sushi in the Heart of Tokmok", short subheading, CTA button "Order Now" (links to WhatsApp), background accent echoing the red semicircle motif from the logo 3. About us — short block about the restaurant: fresh ingredients, atmosphere, summer terrace 4. Menu — card/grid layout with categories (Sushi & Rolls, Pizza, Ramen, Tom Yum), placeholder photos, item names, placeholder prices; card borders/accents in red and orange 5. Features/perks — icons with text: delivery, Wi-Fi, summer terrace, accessible entrance, takeout 6. Reviews — 2-3 review cards with sample customer feedback and a 4.3★ rating (stars in orange) 7. Contact & map — address, hours, phone, WhatsApp button, embedded map (Google Maps placeholder) 8. Footer — logo, social links, copyright, contact info, dark charcoal background with white text Design: - Minimalist, elegant, with a Japanese aesthetic — red/white/charcoal palette pulled from the logo - Clean modern typography, optional subtle Japanese-inspired decorative elements (thin lines, circles, sun motif) - Fully responsive design (mobile, tablet, desktop) - Smooth scroll animations - Floating WhatsApp button in the corner of the screen on all pages, in red Technical details: - Single page with anchor navigation - Mobile-optimized (most users in Kyrgyzstan browse on phones) - Fast loading
